# 06 · 命名

## 已定

| 项 | 值 |
|---|---|
| 英文名 | **Fitly** |
| 仓库 / npm scope | **fitly**、`@fitly/*` |
| 域名 | 好 .com 基本已被注册；`fitly.design` / `fitly.homes` / `fitly.space` 当时查为空 |

英文名不再讨论。下面只谈中文名。

---

## 中文名：建议换掉「装修匠」

### 「装修匠」的问题

| 问题 | 说明 |
|---|---|
| **暗示找师傅** | "匠"= 手艺人/施工方。用户第一反应是"这是个找装修师傅的平台"，而恰恰这个方向已经被否掉了 |
| **与定位相反** | 产品是"你自己在家试一遍"，不是"找人帮你干" |
| **不好搜** | 装修类目里"XX匠""XX家"极度密集，小红书搜索会淹没 |
| **商标难** | 第 37 类（建筑施工）、42 类（设计）里"装修匠"这类组合大概率已被注册或近似在先 |

改名成本现在是**零**——还没有用户、没有内容、没有外链。这是唯一能做这件事的时间点。

### 推荐：**试家**

| 维度 | 表现 |
|---|---|
| 记忆 | 两个字，"试驾 / 试衣 / 试住"的语感，中文母语者秒懂 |
| 口播 | "你先用试家摆一下" —— 顺，能当工具名用 |
| 中英呼应 | 试 = fit / try，家 = home。和 **Fitly** 是同一个意思，不是翻译腔 |
| 定位一致 | 名字直接就是那个动作：**先在"家"里"试"** |
| 扩展性 | 以后加厨房、卫生间、全屋，都还叫试家 |
| 风险 | 需要查商标；"试"字类名称在 35 类可能拥挤 |

**Slogan 备选**（选一个，别都要）：

- 装修前，先试一遍。
- 买之前，先在你家试一下。
- 合不合适，摆过才知道。

### 其他候选与取舍

| 名字 | 好在哪 | 为什么不是首选 |
|---|---|---|
| **装一下** | 轻、口语、适合小红书 | 太像一句口头禅，不像产品名；商标更弱 |
| **样板家** | 有画面感（样板间） | "样板"暗示展示，不暗示"试" |
| **装修先试** | 最直白 | 五个字太长，读起来像口号不像名字 |
| **我家的方案** | 描述清楚 | 太长，无品牌感 |
| **装修匠**（保留） | 已有认知、有"手艺人"温度 | 定位冲突，会持续产生错误预期 |

### 如果不想换

最低成本方案：**保留「装修匠」做公司/系列名，把产品名做成「试家 by 装修匠」**，全局副标题统一为「装修前，先试一遍」，并在 logo 里弱化"匠"字。

但要注意：只要"匠"字还在主视觉里，用户就会持续问"你们能帮我找师傅吗"。**每次解释都是一次成本。**

## 落地顺序

1. **先查商标**：中国商标网（sbj.cnipa.gov.cn）查「试家」，重点看
   - 第 **35** 类（广告、销售、商业经营）
   - 第 **37** 类（建筑施工、室内装修）
   - 第 **42** 类（设计服务、软件设计）
   - 第 **9** 类（可下载软件）
2. **查小红书/微信**：搜「试家」，看有没有同名高粉账号、有没有装企在用（若只是小公司，通常不冲突，但要评估）
3. **查域名**：`shijia.com` 肯定没了，考虑 `shijia.design`、`tryhome.cn`、`fitly.design`（英文站用）
4. 查完再定。**在没查之前，代码里不要出现中文品牌名**——仓库名 `fitly`、包名 `@fitly/*` 都不受影响。
