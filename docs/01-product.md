# 01 · 产品定位

## 一句话

**Fitly 让用户在花钱之前，先在自己家里把这个决定试一遍。**

装修的人最常见的卡点不是"想不到效果"，而是**拿不准尺寸和后果**：

- 2.4 米还是 2.8 米的沙发？
- 衣柜做平开门，前面还够不够走到床边？
- 冰箱放这儿，灶台就在旁边，行不行？

这些问题现在只能靠猜、靠问师傅、或者等装完才发现不对。Fitly 把这件事提前到**下单之前**。

## 目标用户

**主要用户：正在装修或准备装修的屋主，有一套自己的房子（新房交付 / 二手房翻新），装修周期 2–4 个月。**

| 特征 | 说明 |
|---|---|
| 决策窗口 | 集中且短暂。装修期是唯一高频期，装完之后基本不再打开 |
| 决策密度 | 一个装修期要做上百个尺寸相关决定，且大多不可逆 |
| 信息状态 | 知道自己"不懂"，但不知道自己"漏问了什么" |
| 社交场景 | 决定几乎都要跟家人商量——发图、发链接、一起选 |
| 主要触点 | 小红书（找灵感/避坑）、微信（家人群、业主群、私信） |

**非目标用户（第一版不做）**：设计师、装修公司、租房人群、纯看图的灵感用户。

## 核心场景

> 用户在纠结客厅沙发买 2.4 米还是 2.8 米。
> 打开 Fitly，选中自己小区的户型，拖动沙发，俯视图上直接看到：
> **过道还剩多少、阳台门还推不推得开、右侧那个插座会不会被挡。**
> 存两个版本，发链接给家人，晚上一起定下来。

这条链路上有三个关键动作，产品所有功能都服务于它们：

1. **认出自己家**（选户型 / 标尺寸）
2. **摆进去看**（拖拽 + 实时间距）
3. **发给家人定**（存版本 + 分享）

## 竞争位置

| 产品 | 强在哪 | 缺什么 |
|---|---|---|
| 酷家乐 / Homestyler / AI设计家 | 户型库、3D 渲染、家具模型库都很成熟 | 面向"做设计"，学习成本高；不会在操作过程中提醒你漏问了什么 |
| 一兜糖 / 小红书 | 真实案例、避坑内容丰富 | 内容和你家没有几何关系，看完仍然不知道自己家行不行 |
| Fitly | **用你的户型做判断，而不是看图** + 决策点上的实时提醒 | 户型数据是硬成本，内容需要人工核 |

**Fitly 不跟它们比渲染，比的是："它说的这句话，是不是关于我家。"**

## MVP 边界

### 要做

- 一个城市的 3–5 个小区，每个小区几套主力户型（人工建模，不自动识别）
- 只做**客厅**
- 2D 俯视图 + 尺寸标注 + 实时间距
- 拖拽摆放 5–8 件客厅家具（沙发、茶几、电视柜、单椅、边几、地毯）
- 存储 A/B 两版方案，分享链接可只读打开
- **避坑触发器**：点选触发 + 几何触发（详见 02）
- 埋点：谁打开了、摆了几次、存没存、发没发

### 不做

3D · 全屋 · 自动识别户型图 · 全国户型库 · 账号 · 评论/广场/社交 · 装修知识与社区 · 家具商城 · 师傅入驻 · 小程序 · App

## 成功判据

两周后的三个信号，按重要性排序：

| # | 信号 | 怎么看 | 达标线（初期主观判断） |
|---|---|---|---|
| 1 | **能认出自己家** | 用户打开后有没有选中户型并进入试摆 | 选中的比例，以及有没有人问"我们小区有没有" |
| 2 | **愿意反复摆** | 同一用户/同一户型一周内打开次数 | 有人第二次回来改方案 |
| 3 | **愿意发给家人** | 保存方案 / 分享链接比例，以及分享后的打开率 | 有人主动把链接发到家庭群 |

**最想听到的一句话**："我本来想买 2.8 米的，现在决定换 2.4 米了。"

**最没用的反馈**："效果图挺好看的。"

## 收入假设（暂不验证，只记录逻辑）

钱在**决策点**上：用户比较两款沙发的那一刻，品牌才有机会影响购买。

- 短期不做任何收费，先把"保存清单 / 问购买链接"这个行为测出来
- 如果用户真的会点商品、会存清单，家具品牌合作才成立
- 更远的可能是：户型模板 + 内容服务同小区的一批屋主（一份模板服务多人，边际成本低）

## 最大风险

| 风险 | 说明 | 应对 |
|---|---|---|
| **户型数据** | 搜到一张图容易，做成"能试摆"的模板难：要确认版本、墙和门窗、校准尺寸 | 只做能拿到授权图纸的少数小区；搜不到就留"帮我找户型"入口 |
| **尺寸精度** | 用户量不准、也不愿意量 | 用小区户型库做精度来源；同时提供"标一段已知长度"的兜底校准 |
| **低频** | 装完就不用了 | 接受低频，靠"同小区复用"摊薄成本，不追求日活 |
| **内容准确性** | 避坑写错会害人（水电燃气） | 见 02 的内容红线：只提醒去问谁，不给具体做法 |
