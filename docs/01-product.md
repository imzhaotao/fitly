# 01 · 产品定位

## 一句话

**Fitly 让用户在花钱买家具、定家电与软装之前，先在自己家高质感 3D 空间里把这个决定试一遍。**

准备买家具或做软装布局的人，最常见的卡点不是“缺几张网图灵感”，而是**拿不准放进自家后的真实体量、净空与点位冲突**：

- 2.4 米还是 2.8 米的沙发？放进客厅会不会显得堵、阳台门还推不推得开？
- 卧室买 1.8 米的床 + 平开门衣柜，前面过道还够不够开门和铺床？
- 厨房冰箱紧挨着灶台放，散热缝够不够、买完洗碗机和地柜之间动线顺不顺？

这些问题现在只能靠猜、拿卷尺满屋比划、或者等送到家才发现放不下。Fitly 把这件事提前到**下单之前**。

## 目标用户

**主要用户：正在买家具、定制柜或定软装布局的屋主——无论自己装还是已请半包/全包师傅与设计师，依然想在下单前亲眼核对尺寸与空间感的决策者。**

| 特征 | 说明 |
|---|---|
| 真实需求 | 哪怕请了师傅/设计师，屋主仍要自己挑沙发、床、冰箱、衣柜；下单前最想确认“放我家是不是太大、挡不挡门和插座” |
| 决策窗口 | 集中且高客单价。选沙发、买床衣柜、定厨电布局阶段高频使用 |
| 决策密度 | 要做几十上百个与尺寸、位置、遮挡相关的决定，大件退换或返工代价极高 |
| 社交与协作 | 改好的 3D 方案既要发到家庭群投票，也常发给设计师/工长问一句“这样摆行不行” |
| 主要触点 | 小红书（找灵感/避坑）、微信（家人群、业主群、设计师沟通群） |

**非目标用户**：重 CAD 出施工图的专业设计师、硬装施工队、纯刷图不量尺寸的灵感用户。

## 核心场景

> 用户已经找了施工方，正在纠结客厅沙发买 2.4 米还是 2.8 米，或者卧室衣柜选平开门还是推拉门。
> 打开 Fitly，先选一套同开间、带有生活取舍的**可编辑设计模板**（比如“一家人观影型”或“留出亲子活动区型”），把开间改成自家的 3.3 米，再把模板里的沙发换成自己看中的 2.8 米款式；
> 进入 **3D 居家空间**，切到**第一人称平视**感受空间是否拥堵，再切到**顶视量尺**看净空——系统实时亮起红线提醒：
> **“阳台门扇会扫到贵妃位”“沙发右侧离地 40cm 的插座会被靠背挡住”。**
> 云端自动保存版本快照，勾选两版生成对比短链发到家庭群或发给设计师确认，家人免登录直接点“我选这版”。

这条链路上有四个关键动作：

1. **选一个好起点并调成自家尺寸**（可编辑设计模板 / 参数改尺 / 底图辅助描墙）
2. **高质感 3D 改尺试摆与实时避坑**（3D 斜角 / 人眼平视 / 顶视量尺切换 + 几何触发提醒）
3. **多方案云端快照与确定性对比**（任意两版差异一目了然）
4. **分享给家人或设计师协同定案**（短链直开 + 轻量投票与批注）

## 竞争位置

| 产品 | 强在哪 | 缺什么 |
|---|---|---|
| 酷家乐 / Homestyler / AI设计家 | 写实渲染图库全、适合设计师做全案施工 | 对 C 端屋主太重，学习曲线陡；不会在拖家具时针对自家点位做实时间距避坑 |
| 一兜糖 / 小红书 | 真实装修案例与文字避坑帖丰富 | 内容与你家没有几何关系，看完仍不知道自己家放不放得下 |
| Fitly | **零门槛高质感 3D + 实时毫米级净空 + 3D 几何联动避坑 + 家人投票对比** | 聚焦买前软装试装与布局决策，1 分钟内得到明确结论 |

**Fitly 的核心壁垒不是单纯能看 3D，而是：“它结合你家的真实尺寸，在下单前拦住那个具体的问题。”**

## 完整产品范围（Phase 1 最优架构）

### 要做

- **三大高频空间全覆盖**：**客厅 + 卧室 + 厨房**（多房间可切换，支持扩展玄关/阳台）
- **可编辑设计模板 + 三合一户型建图**：
  1. 同一典型户型提供多套功能取舍各异的**可编辑设计模板**（如客厅“观影优先型” vs “亲子活动留空型”），给用户一个值得改的起点
  2. 参数化房间尺寸编辑器（改开间、进深、门窗位置与基于墙体朝向的开门方向）
  3. 上传 2D 户型图底图 → **辅助墙线识别 + 两点比例尺校准 + 自由描墙精修**
- **高质感轻量 3D 引擎**：PBR 材质与柔和光影（地板/墙面/玻璃/织物质感）、高辨识度多部件家具（可切换常用尺寸规格与配色）、实时 3D 尺寸标尺线、以及 **3D 斜角 / 第一人称平视 / 正交顶视** 三视角切换
- **完整避坑引擎**：首批 31 条覆盖客厅（11）、厨房（11）、卧室（9），含 L1 核对式提醒 + L2 3D 几何（方向净空、高度遮挡、门扇扫掠、厨电三角动线）+ L3 空间 + L4 下单前确认；支持基于 `auditPlan` 的稳定快照冲突审计
- **云端快照与分享投票**：免登录也可试用并自动存快照；支持任意两版同场景/分屏对比、生成短链分享页（SSR 预览卡片）、家人在分享页直接点选投票或留一句话备注

### 明确不做（产品与合规边界）

硬装拆改与承重墙判断 · 施工工艺与水电/燃气/防水工程参数指导 · 外部平台户型图抓取 · 透视照片直接生成户型 · 师傅入驻平台 · 强制登录后才能开始试摆

## 成功判据

| # | 信号 | 怎么看 | 达标标准 |
|---|---|---|---|
| 1 | **进得来、建得出** | 从进入工具到完成户型准备（选模板/改尺寸/描墙）并开始拖拽的比例 | 手机和电脑端都能顺滑完成一次家具布局 |
| 2 | **避坑能改变决策** | 触发提醒后调整位置/换小一档尺寸/复制提问清单的比例（`pitfall_acted`） | 用户因 3D 提醒明确修正了家具尺寸或摆位 |
| 3 | **愿意对比与协同定案** | 使用版本对比、生成分享短链并收到家人打开/投票的比例 | 分享链接在微信端产生真实浏览与家庭投票互动 |

## 收入假设（暂不验证，预留接口）

钱在**选品决策点**上：用户比对 2.4m 和 2.8m 沙发、或确认某尺寸冰箱可嵌入时，基于真实可放尺寸的选品清单与品牌合作才成立（始终保持避坑内容中立）。

## 核心风险与应对

| 风险 | 说明 | 应对 |
|---|---|---|
| **手机端 3D 拖拽体感** | 触摸屏单指旋转视角和移动家具易冲突、手指易遮挡 | 严格手势隔离（选中锁定相机，仅地面拖拽）+ 贴墙/直角智能吸附 + 外置快捷尺寸/旋转栏 + 顶视图模式 |
| **底图识别精度期望** | 户型图清晰度不一，全自动识别可能丢墙或误识别门窗 | 采用“辅助预提取 + 用户两点标尺校准 + 可拖拽墙角精修”人机协同，确保最终几何 100% 可控 |
| **内容专业与合规边界** | 误写硬装拆改或强电燃气施工参数会带来安全与法律风险 | 死守软装边界：不碰拆墙承重；涉水电燃气防水只给风险提醒与 `ask` 提问清单 |
