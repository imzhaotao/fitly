# 屋主访谈 01 · 住进去以后才发现的问题

2026-11-25 整理。本次讨论来自一位已入住的屋主。下面区分入住体验、群聊中提出的想法和产品假设。单次访谈可以提供案例，发生频率和付费意愿仍待验证。

## 屋主经历了什么

| 访谈线索 | 对产品的启发 |
|---|---|
| 屋主在小红书、抖音找过攻略，也参考过亲友装修经验。水电点位由自己出想法，再交给工人实施。 | 即使有施工人员，屋主仍需要在现场做选择。值得测试的使用时机是定点位和确认图纸前。 |
| 餐桌插座设在桌下，入住后希望当初装在桌上方。选择桌下的理由是「我就是看别人都装下面的」。屋主也拿不准上方是否有别的不便。 | 看过案例仍可能忽略自己每天怎么用。提示应让屋主比较插拔是否顺手、线会经过哪里。吃火锅是访谈者提出的例子，具体使用原因仍待确认。 |
| 床头柜位置也略有不合理，但尚未说清是哪里不便。除此之外，屋主觉得整体住起来还行。 | 先了解一次实际使用过程，再决定应提示柜宽、摆位还是其他问题。 |
| 屋主觉得灯光点少，也明确提到多装灯和插座都要花钱。 | 有些遗憾来自主动控制预算。提示应说明增加一个点位能改善哪种使用场景，让屋主决定这笔钱值不值得花。 |
| 对话提到曾用家装软件看效果，熟人还开过会员。屋主觉得最恼火的是「硬装，装了就不好改了」。 | 3D 预览已有替代工具。应优先验证在硬装确定前，通过未来的家具布局发现遗漏，是否值得屋主再打开一个工具。熟人买过会员不能证明屋主愿为避坑付费。 |

## 首个可测试的场景

屋主在客餐厅模板里摆好餐桌，选择“准备定水电”，系统提示：“站在你平时插拔电器的那一侧，桌边能直接够到插座吗？插上线以后，线会从哪里经过？”用户可以比较两个位置，并把需要确认的位置发给工人。

只有用户确认了桌子和插座高度，才显示两者的高差。插座在桌下可以是合理选择。验收时观察屋主是否因此补量一个尺寸、改动一个点位，或主动向工人确认。另记录提醒是否出现得太迟。

## 群聊提出的扩展方向

- **材料对比。** 聊到洗手台原有玻璃胶发霉，换了另一种白色胶后暂时未再出现霉斑。产品可测试“这种材料住久了怎样、怎么清洁、换起来麻烦吗”的对比卡。替代胶的名称、使用时间和环境都未知，暂时无法归因或推荐型号。
- **家庭需求。** 同一布局对不同家庭有不同取舍。先问实际行为，例如常用餐人数、是否常在桌上用电、衣服习惯挂还是叠，再决定展示哪条提示。避免仅凭性别或年龄推断偏好。
- **适老化。** 卫生间扶手和防跌倒是讨论中提出的方向。仍需访谈老人、照护者和相关专业人士，了解他们在什么动作、什么位置需要支持，再决定如何展示和复核内容。
- **AI 整理经验。** 可让 AI 汇总访谈和有使用授权的资料，整理成“何时提醒、适用条件、该问谁”。社交平台上的个案可以提供选题线索，发布前应核对出处和适用范围。“多装柜、多留插座”以及群聊提到的水电走向，都不能直接写成通用施工规则。

## 下一轮最值得追问

1. 定餐桌插座前，有没有确定桌子的位置、尺寸？是谁在什么时候请你确认点位的？
2. 床头柜不方便的最近一次是什么时候，当时想做什么？如果重来，你会改哪个位置？
3. 如果只能多花一笔钱，你会优先改哪一处？有没有明知道不完美、现在仍会保留的选择？

本次访谈支持把餐桌插座纳入首个演示。材料对比、适老化和新增空间先留作调研方向，等更多独立案例再调整开发优先级。
