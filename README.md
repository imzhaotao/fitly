## 三条已经定下来的决策

1. **先做 Web（手机优先的响应式 H5）**，不做小程序、不做 App。
   理由：核心未知数是"摆家具在手机上会不会很烦"，这需要一天能改五遍的载体。
2. **第一版只做客厅，只做 2D 俯视图 + 尺寸标注，不做 3D。**
   用户决定"2.8 米沙发能不能放"，靠的是间距和过道宽度，不是渲染图。
3. **避坑内容不是知识库，是跟几何数据联动的触发器。**
   用户没点，系统也能发现"你家插座会被沙发挡住"——这是别人抄不走的部分。

## 第一版明确不做

3D 渲染 · 全屋 · 户型自动识别 · 全国户型库 · 账号体系 · 评论社交 · 师傅入驻 · 家具商城
