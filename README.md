# Fitly

> **买之前，先在你家 3D 试一下。**

面向中国 C 端屋主的**装修软装与家具试装决策工具**。用户在手机或电脑上选择典型户型、参数化调整尺寸，或上传自家户型图辅助描墙建出 3D 家居空间，实时拖动家具、切换风格材质与视角，在“做决定的那一刻”直观看到尺寸净空、3D 体量与潜在避坑点，并把对比方案发给家人投票定稿。

**当前状态：设计文档已按最优方案定稿，待初始化代码。**

---

## 核心定位与设计原则

1. **高质感轻量 3D + 三视角无缝切换。**
   采用 **React Three Fiber + PBR 质感材质 + 柔和光影**（木地板、墙面质感、真实比例门窗与家具模型），支持 **3D 漫游/斜角视角**、**人眼平视视角** 与 **正交顶视量尺视角** 一键切换，兼顾空间氛围与毫米级精度。
2. **客厅 / 卧室 / 厨房核心三空间同步覆盖。**
   不再受人工开发工期限制，首版完整覆盖屋主大件决策最高频的三大空间，配套 30+ 条与 3D 几何联动的避坑触发器。
3. **Next.js 全栈一体化 + 真实云端持久化。**
   使用 Next.js App Router + Drizzle ORM + 数据库存储，支撑**自动快照、任意两版对比、短链 SSR 分享页**以及**家人点赞/选品投票**。
4. **只做软装与布局避坑，严守法律与安全边界。**
   拆墙/承重墙判断/施工工艺参数属于硬装范畴，Fitly 不碰；涉及水电、燃气、防水邻接时只给风险提示与“问谁/问什么”清单。

## 明确不做（产品与合规边界，非工期取舍）

硬装拆改与承重判断 · 师傅入驻平台 · 外部平台户型抓取 · 照片直接生成无比例户型 · 脱离几何的装修百科 · 强制登录后才能试摆
